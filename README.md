# LocalLux

LocalLux is a fully functional web application designed for apartment rentals. It allows users to list properties, search for accommodations, book stays, and leave reviews. The platform is inspired by popular rental services and aims to deliver a streamlined user experience.

---

## **Overview**
StayConnect simplifies the process of finding and managing short-term accommodations. Whether you're a host looking to rent out your property or a traveler searching for the perfect place to stay, StayConnect provides a robust solution.

### **Key Features**
- User accounts for both guests and hosts.
- Apartment listings with detailed descriptions, images, and facilities.
- Search functionality with filters for dates, prices, and amenities.
- Booking system to manage reservations.
- Messaging and review systems for seamless interactions.
- Export data in XML or JSON format.

---

## **Technology Stack**
### **Frontend:**
- **EJS Templates**: For rendering dynamic web pages.
- **Bootstrap**: For responsive and user-friendly design.

### **Backend:**
- **Node.js**: Server-side environment.
- **Express.js**: Routing and middleware framework.
- **MongoDB**: Database for storing user, apartment, and booking data.

---

## **Functionalities**
### For Guests:
- Create an account, log in, and log out.
- Search for apartments by date, price, and amenities.
- Book stays and manage reservations.
- Communicate with hosts through messages.
- Leave reviews for apartments and hosts.

### For Hosts:
- Create an account, log in, and log out.
- Upload apartments with images and detailed descriptions.
- Manage bookings and communicate with guests.
- Respond to reviews and maintain ratings.
